# ✂️ PDF Tools — Split & Merge PDFs Online

A free, privacy-first PDF toolkit that runs entirely in your browser. No servers, no uploads, no sign-ups — your files never leave your device.

### 🔗 [Use it live → sss-r.github.io/pdf-splitter](https://sss-r.github.io/pdf-splitter/)

---

## Features

| Feature | Description |
|---|---|
| ✂️ **Split PDFs** | Extract specific pages or ranges into separate files |
| 🔗 **Merge PDFs** | Combine up to 3 PDF files into a single document |
| 🔒 **100% Private** | All processing happens client-side — nothing is uploaded |

## How It Works

1. **Upload** your PDF file(s) via drag & drop or file picker
2. **Choose your action** — set page ranges to split, or select files to merge
3. **Download** your processed PDFs instantly

## Tech Stack

- **React 19** + **Vite 7**
- **[pdf-lib](https://pdf-lib.js.org/)** for client-side PDF manipulation
- **[Lucide React](https://lucide.dev/)** for icons
- Deployed on **GitHub Pages** via GitHub Actions
